📊 Customer Churn Prediction App

🚀 Project Overview

This project is a Machine Learning web application built using Streamlit to predict whether a customer is likely to churn or not.

It uses Logistic Regression and Label Encoding to analyze customer data and provide real-time predictions.

🧠 Machine Learning Details

* Algorithm: Logistic Regression
* Encoding: Label Encoding
* Problem Type: Binary Classification

🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn

📁 Dataset

* Telco Customer Churn Dataset
* Contains customer demographics, services, and billing information

▶️ How to Run Locally

1. Clone the repository:

git clone https://github.com/your-username/customer-churn-streamlit.git
```

2. Navigate to the folder:

```
cd customer-churn-streamlit
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the app:

```
streamlit run main.py
```
